# ColorSweeper 解題器

手機推理遊戲 **ColorSweeper** 的網頁解題器。輸入盤面後，它不直接給答案，而是**一步一步告訴你下一格怎麼推出來**，並用中文說明理由。

👉 **線上使用：<https://yuutatsubasa.github.io/Color-Sweeper-Solver/>**

> 這是非官方的玩家自製工具，與遊戲開發商無關。

## 功能

- **逐步提示**：每次只給一步推論，並在盤面上框出用到的線索與要填的格子。也可以選擇「先只標出要看的線索」，自己想過再看答案。
- **推理由淺到深**：

  | 層級 | 推法 | 例子 |
  |---|---|---|
  | Lv1 基礎 | 只看一個線索 | 「綠1 周圍可能是綠的只剩 E2 → E2 是綠」 |
  | Lv2 比對 | 比較兩個同色計數線索的重疊區 | 「紫4 專屬候選只有 3 格 → 共同區至少 1 格紫 → 紫1 已補滿」 |
  | Lv3 假設 | 假設某格是某色，推出矛盾 | 「假設 B1 是紫 → A2 是黃 → 綠4 湊不滿 → 矛盾」 |
  | Lv4 窮舉 | 前面都推不動時才用電腦窮舉 | — |

- **跟著遊戲進度輸入新線索**：遊戲中填好格子後可能冒出新數字。解題器會把剛解出的格子標上 **?**，推不下去時提醒你把新線索輸入進來。
- **符號與密碼的已知資訊面板**：顯示每個符號目前知道的「同色／異色」圖案，以及密碼推出了哪些顏色。
- 盤面自動存在瀏覽器裡；可以用 JSON 匯入、匯出盤面。
- 手機可用，支援深色模式。

## 支援的規則

2 色、3 色、4 色都可以，規則也可以在同一題裡混搭。

| 規則 | 放在哪裡 | 意義 |
|---|---|---|
| 基本 | 格子 | 數字＝周圍 8 格中與線索同色的格數 |
| 射線 | 格子 | 數字＝箭頭方向上一路到邊界，與線索同色的格數 |
| 騎士 | 格子 | 數字（預設 1）＝騎士跳得到的格子中與線索同色的格數 |
| 棒狀 | 格子 | 數字＝線索所在方塊在指定方向（橫／直）上的長度 |
| 多邊形 | 格子 | 線索所在區域（上下左右相連的同色格）的形狀，可旋轉、不可翻轉 |
| 符號 | 格子 | 同一種符號共用一個「8 個方向同色／異色」的圖案 |
| 成對 | 相鄰兩格 | 兩格的基本規則數字相同 |
| 對稱 | 格子 | 兩個互相指向的線索之間（含兩端）顏色排列對稱 |
| 密碼 | 格子＋行列 | 盤面上有一組長度 3 的密碼；行列的 ◎／⊘ 表示該行列有沒有依序連續出現密碼 |
| 計數 | 行列 | 數字＝該行列中指定顏色的格數 |
| 方格 | 行列 | 數字＝該行列中指定顏色的方塊數 |
| 連線 | 行列 | 數字＝該行列中最長方塊的長度 |
| 雙格 | 行列 | 數字＝該行列中長度剛好 2 的方塊數 |
| 主要 | 行列 | 皇冠＝該色是唯一最多；⚔＝最多的顏色有並列 |
| 預覽 | 格子 | 數字先顯示、線索格本身顏色未知（顏色設為「未知」即可） |
| 偽裝 | 整盤設定 | 所有非零偶數都可能是實際值的兩倍 |
| 困難 | — | 需要假設推理，對應解題器的 Lv3 |

## 使用方式

1. **① 輸入盤面**
   - 設定大小和顏色數。
   - 點格子設定顏色與線索。沒有數字的色格（原本就沒有、完成後消失、或已填好）只設顏色就好。
   - 點左側列號或上方欄號，可以設定行列外的線索。
   - 鍵盤：方向鍵移動、`Q` `W` `E` `R` 設顏色、`0`–`8` 設數字、`Del` 清除。
2. **② 逐步解題**
   - 按「提示下一步」看推理，按「套用並繼續」前進。
   - 遊戲中出現新線索時，點那一格輸入。數字可以直接按鍵盤，`N` 代表沒有線索。

## 開發

純 HTML、CSS、JavaScript，不需要建置，也沒有外部套件。

```
index.html   頁面
app.js       介面與互動
solver.js    解題核心（瀏覽器與 Node 都能載入）
style.css    樣式
tests/       隨機盤面的推理正確性測試
```

本機直接用瀏覽器開 `index.html`，或在專案資料夾開一個靜態伺服器。

正確性測試會隨機產生已知答案的盤面（涵蓋各種規則與組合），逐步求解，並檢查每一步推論都與答案一致：

```bash
node tests/soundness.js
```

### 解題核心的設計

- 每格是一個「顏色候選集合」，符號圖案的 8 個方向也是額外的變數。
- 每條規則都轉成一個「限制」，提供 `feasible(候選狀態)`：在目前狀態下是否還可能成立，不可能時附上原因。
- 推理依序嘗試：
  - Lv1：單一限制。常見情況有專屬的直觀說明，其他情況逐一試每個候選值。
  - Lv2：兩個計數限制的重疊比對。
  - Lv3：假設法，找出最短的矛盾鏈。
  - Lv4：窮舉搜尋。
